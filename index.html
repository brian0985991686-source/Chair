1. Production Output (生產產量)
-
終點站完工產品數
2. Production Attainment (達成率)
-
實際產量 ÷ 目標產量
3. On-Time Completion Rate (準時完成率)
-
各筆作業秒數 ≤ 標準工時 之比例
4. First Pass Yield (首次通過率)
-
狀態為 COMPLETED 且無重複重工比例
5. Cycle Time (整線週期時間)
-
平均每產出一件所需整線時間
6. Employee Productivity (員工生產力)
-
假設每站 1 人之平均產出
